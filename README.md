# Syracuse Block Condensed Variable

Repository for a font specimen landing page for **Syracuse Block Condensed**, a proprietary variable display font for Syracuse University.

The font was originally created by former Division of Marketing creative director Stos DeVaris, and since 2022 has been updated and maintained by [Joey Sweener](https://jsweener.com).

https://sweenerjoey.github.io/syr-block-condensed
