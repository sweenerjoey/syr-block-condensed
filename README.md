# Syracuse Block Condensed Variable

**Syracuse Block Condensed** is Syracuse University's proprietary variable display typeface. The font was originally created by former Division of Marketing creative director Christos "Stos" DeVaris, and since 2023 has been revised and maintained by [Joey Sweener](https://jsweener.com).

You can [view the specimen](https://sweenerjoey.github.io/syr-block-condensed), or [learn more about the font's development](https://medium.com/@SweenerJoey/syracuse-block-condensed-variable-3c71e555a3af).
